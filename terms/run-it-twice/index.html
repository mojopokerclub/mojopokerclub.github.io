What does run it twice mean in poker

How running an all-in twice works, whether it changes your odds and what Run it Multi-Times is in the club. Example: aces against kings.

All termsTake a seat
Pot and forced bets
Run it twice is a way to settle an all-in before the river: the remaining board cards are dealt twice, and each run decides half the pot. The odds do not change, but results get steadier: losing the whole pot to one card becomes less likely.

How it works

  1. Two players go all-in, say preflop.
  2. If the table allows it and the players agree, the remaining cards are dealt twice in a row. Cards from the first run are not reused in the second.
  3. The first run decides half the pot, the second run the other half.
  4. If one player wins both runs, they take the whole pot. If each wins one, the pot is split.

Does running it twice change the odds

No. Your expected value is the same: with 80% to win, one run earns you 80% of the pot on average and so do two. Only the spread of results (variance) changes: fewer painful losses of the whole pot, and fewer whole-pot wins with the worse hand.

Run it Multi-Times in the club

In ClubGG the setting is called Run it Multi-Times: the board can be dealt two or three times. MOJO tables with it are tagged in the lobby. The all-in players decide, if the table allows it.
