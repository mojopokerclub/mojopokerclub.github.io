Что такое run it twice в покере

Как работает прогон олл-ина два раза, меняет ли он шансы и что такое Run it Multi-Times в клубе. Пример: тузы против королей.

Банк и обязательные ставки
Run it twice — способ разыграть олл-ин, когда до ривера остались неоткрытые карты: оставшиеся карты борда раздают дважды, и каждый прогон разыгрывает половину банка. Шансы игроков не меняются, но результат становится стабильнее: проиграть весь банк из-за одной карты сложнее.

Как это работает

  1. Два игрока идут олл-ин, например на префлопе.
  2. Если стол это разрешает и игроки согласны, оставшиеся карты раздают два раза подряд. Карты первого прогона во втором не используются.
  3. Первый прогон разыгрывает половину банка, второй — вторую половину.
  4. Если оба прогона выиграл один игрок, он забирает весь банк. Если по одному — банк делится.

Тузы выиграли первый прогон, короли собрали сет во втором. Каждый получает половину банка, хотя при одном прогоне кто-то один забрал бы всё.

Меняет ли run it twice шансы

Нет. Математическое ожидание то же самое: если у вас 80% на победу, при одном прогоне вы в среднем выигрываете 80% банка, и при двух тоже. Меняется только разброс результатов (дисперсия): реже бывают обидные проигрыши всего банка, но и реже — выигрыши всего банка с худшей рукой.

Run it Multi-Times в клубе

В ClubGG эта настройка называется Run it Multi-Times: борд можно раздать два или три раза. В лобби клубов MOJO такие столы отмечены пометкой. Решение принимают игроки в олл-ине, если стол это разрешает.
