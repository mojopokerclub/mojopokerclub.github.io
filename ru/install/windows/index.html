Как установить ClubGG на Windows

Пошаговая инструкция со скриншотами: от скачивания до первого запуска — 8 шагов, несколько минут.

WindowsmacOSiPhone / iPadAndroid
1
Нажмите Download на clubgg.com

Откройте clubgg.com и нажмите кнопку Download в правом верхнем углу — на компьютере сразу скачается установщик ClubGG для Windows (.msi, около 370 МБ).

Открыть clubgg.com
2
Откройте скачанный файл

Откройте загрузки браузера и запустите файл ClubGG_….msi.

3
Подтвердите запуск

Windows спросит, хотите ли вы запустить файл. Издатель — NSUS Limited (разработчик ClubGG). Нажмите «Запустить».

4
Мастер установки — Next

Откроется ClubGG Setup Wizard. Нажмите Next.

5
Примите лицензионное соглашение

Поставьте галочку «I accept the terms in the License Agreement» и нажмите Next.

6
Папка установки

Оставьте папку по умолчанию C:\Program Files\ClubGG\ и нажмите Next.

7
Нажмите Install

Нажмите Install и подождите минуту — установка пройдёт автоматически. Если Windows запросит разрешение — нажмите «Да».

8
Запустите ClubGG с рабочего стола

На рабочем столе появится ярлык ClubGG — откройте его и войдите или создайте аккаунт.

Читать инструкцию
Примечание: Требуется Windows 10 или новее. Убедитесь, что у вас достаточно места на диске.
